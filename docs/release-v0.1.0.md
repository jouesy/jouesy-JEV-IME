JEV 智慧注音 V0.1.0 是 Windows 11 x64 的離線注音輸入法測試版。

下載 **JEV-Setup-0.1.0-win-x64.exe**，雙擊安裝；安裝完成後登出再登入，
按 **Win + Space** 選取「JEV 智慧注音」。一般使用者不需要自行編譯。

包含 x64／x86 TSF DLL、注音引擎、候選選字、設定程式、個人詞庫及解除安裝程式。
解除安裝會保留個人词庫與設定。

發佈流程在 Windows runner 編譯原生程式並執行九個 JEV 測試，再檢查 EXE 的
安裝、两種 COM 註冊、背景引擎啟動、目前帳號的輸入法啟用、解除安裝及個人資料保留。

此為尚未簽章的測試版。Windows 11 的 Word／Chrome／LINE 實機相容性仍待驗收；
Jev API、語音輸入與智慧文字修正尚未加入。

`.sha256` 檔提供安裝檔 SHA-256 校驗值。
